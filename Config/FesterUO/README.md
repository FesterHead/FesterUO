# FesterUO Custom Shard Configurations

This directory (`Config/FesterUO/`) contains custom gameplay and world tuning configuration files authored specifically for the **FesterUO** private shard.

---

## Configuration Inventory

| Configuration File | Scope | Consuming Systems & Purpose |
| :--- | :--- | :--- |
| [`BulkOrders.cfg`](BulkOrders.cfg) | `BulkOrders` | **Consuming Scripts**: `custom-scripts/FesterUO/BulkOrderMaster.cs`<br>Configures the unified Bulk Order Master NPC hub: NPC mobile name (`NPCName=Artisan Guildmaster`), title (`NPCTitle=the Bulk Order Master`), minimum skill required to claim orders (`MinSkillRequired=0.1`), and maximum interaction range (`InteractionRange=4`). |
| [`Crops.cfg`](Crops.cfg) | `Crops` | **Consuming Scripts**: `custom-scripts/FesterUO/Crops.cs`<br>Configures procedural crop respawn timing intervals (`MinRespawnMinutes=6.0`, `MaxRespawnMinutes=12.0`), per-tile field spawn probability (`SpawnChance=0.50`), facet enablement (`SpawnTrammel=True`, `SpawnFelucca=True`, `SpawnTokuno=True`), and configurable crop types (`CropTypes`). |
| [`Harvest.cfg`](Harvest.cfg) | `Harvest` | **Consuming Patches**: `03-harvest-amount`, `04-fishing-delay`, `05-mining-delay`, `06-lumberjacking-delay`<br>**Consuming Scripts**: `custom-scripts/FesterUO/CustomAutoTools.cs`<br>Configures skill-scaled resource yields (`SkillScalingYield=True`, `MaxSkillYieldMultiplier=12.0`, `SkillCurveExponent=2.0`, `DrainVeinWithBonusYield=False`), tool delays (`FishingDelay=2.0s`, `MiningDelay=1.0s`, `LumberjackingDelay=1.0s`), mounted mining toggle (`AllowMountedMining=True`), and sheep wool regrowth interval (`SheepWoolRegrowthMinutes=30.0`). |
| [`HoldingBox.cfg`](HoldingBox.cfg) | `HoldingBox`, `Vendors` | **Consuming Scripts**: `custom-scripts/FesterUO/HoldingBox.cs`<br>**Consuming Patches**: `36-holding-box-vendor`<br>Configures maximum items (`HoldingBox.MaxItems=1000`), maximum weight (`HoldingBox.MaxWeight=0` for unlimited), default hue (`HoldingBox.DefaultHue=1175` for Midnight Navy), and Tinker NPC deed purchase price (`Vendors.HoldingBoxDeedCost=100000`). |
| [`Imbuing.cfg`](Imbuing.cfg) | `Imbuing` | **Consuming Patches**: `38-uncapped-imbuing`<br>Configures uncapped imbuing mechanics: remove 5-property limit (`Imbuing.UncapPropertyCount=true`), remove property weight limit (`Imbuing.UncapPropertyWeight=true`), allow multiple special effects like hit areas, hit spells, and multiple slayers (`Imbuing.AllowMultipleSpecialEffects=true`), require existing properties to be upgraded rather than downgraded (`Imbuing.OnlyHigherExistingValues=true`), difficulty intensity ceiling (`Imbuing.MaxDifficultyWeight=450`), and minimum success chance floor (`Imbuing.MinSuccessChance=5.0`). |
| [`Reagents.cfg`](Reagents.cfg) | `Reagents` | **Consuming Scripts**: `custom-scripts/FesterUO/WildernessReagents.cs`<br>Configures automated wilderness ground reagent spawning (`Enabled=True`, `MaxGroundReagents=500`, `RespawnIntervalMinutes=15`, `MinSpawnAmount=1`, `MaxSpawnAmount=3`, `SpawnTrammel=True`, `SpawnFelucca=True`). |
| [`SkillTrainer.cfg`](SkillTrainer.cfg) | `SkillTrainer` | **Consuming Scripts**: `custom-scripts/FesterUO/SkillTrainer.cs`<br>Configures the fundamental skill trainer NPC: target training skill level (`TargetSkillLevel=40.0`), gold fee per skill (`GoldCost=1000`), maximum interaction range (`InteractionRange=4`), bank balance gold fallback (`AllowBankGold=True`), and paperdoll NPC title (`TrainerTitle=the Skill Trainer`). |
| [`SlowSkillGrind.cfg`](SlowSkillGrind.cfg) | `SlowSkillGrind` | **Consuming Scripts**: `custom-scripts/FesterUO/SlowSkillGrind.cs`<br>Configures progressive hours-based skill gain past 100 without PowerScrolls (`Enabled=True`, `Tier1Hours=6.0` [100-105], `Tier2Hours=12.0` [105-110], `Tier3Hours=18.0` [110-115], `Tier4Hours=24.0` [115-120], `MaxSkillCap=120.0`). |
| [`Stables.cfg`](Stables.cfg) | `Stables` | **Consuming Patches**: `08-stable-slots`<br>Configures baseline stable stalls (`BaseSlots=12`) granted to every character before taming skill bonuses. |
| [`TrashBarrel.cfg`](TrashBarrel.cfg) | `TrashBarrel` | **Consuming Scripts**: `custom-scripts/FesterUO/TrashBarrel.cs`<br>Configures multi-floor house trash barrel crafting and mechanics: recipe toggle (`TrashBarrel.CraftingEnabled=true`), required Carpentry skill range (`TrashBarrel.MinSkill=65.0`, `TrashBarrel.MaxSkill=90.0`), crafting material costs (`TrashBarrel.OakBoards=30`, `TrashBarrel.ShadowIronIngots=15`, `TrashBarrel.SulfurousAsh=5`), and deed recovery on chop/pack up (`TrashBarrel.ChopReturnsDeed=true`). |
| [`UniversalDyeTub.cfg`](UniversalDyeTub.cfg) | `UniversalDyeTub` | **Consuming Scripts**: `custom-scripts/FesterUO/UniversalDyeTub.cs`<br>Configures the per-use gold fee (`CostPerUse=1000`) for the Highlander Universal Dye Tub. |
