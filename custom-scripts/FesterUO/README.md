# FesterUO Custom Scripts

This directory (`servuo/custom-scripts/FesterUO/`) contains custom gameplay systems, utilities, and quality-of-life enhancements authored specifically for the **FesterUO** private shard.

---

## Script Inventory

| Script | Purpose & Mechanics | Commands / Trigger |
| :--- | :--- | :--- |
| [`CustomAutoTools.cs`](CustomAutoTools.cs) | Enchanted gathering and harvesting tools with automated processing: auto-smelt ore to ingots, auto-saw logs to boards, auto-fillet fish, corpse hide skinning, sheep shearing, and area crop scything. | Tool usage / harvest |
| [`FesterUOGuideBook.cs`](FesterUOGuideBook.cs) | Blessed reference tome detailing satchel mechanics, auto-tools, backpack fallback routing, open housing, runebook & blank runes, home fixtures (Ankh & Moongate), re-deeding instructions, stable stalls, Hunter's Bestiary treatise progression, and player commands (`[Bestiary`, `[rbank`, `[c`, `[say`, `[GetSanctuary`, `[LootFilter`, `[ApexHunt`, `[SlowGrind`). | Distributed to first character per account |
| [`GlobalChat.cs`](GlobalChat.cs) | Lightweight server-wide broadcast communication for private duo play, outputting in distinct cyan text across all facets. | `[c <message>`, `[chat <message>` |
| [`HarvestConfig.cs`](HarvestConfig.cs) | Reads respawn intervals and bank capacities from `Harvest.cfg` and dynamically applies them to Mining and Lumberjacking systems on startup. | `[HarvestInfo` (GM) |
| [`HouseMoongateAddon.cs`](HouseMoongateAddon.cs) | Custom house-placed moongate addon with full facet destination navigation (`MoongateGump`) and axe re-deeding support (`BaseAddonDeed`). | Double-click or walk through to travel; axe to re-deed |
| [`RemoteBank.cs`](RemoteBank.cs) | Remote bank access command allowing players to open their personal bank container from any location, with safety checks for criminal status and death. | `[rbank` |
| [`ResourceSatchel.cs`](ResourceSatchel.cs) | Blessed, weight-free storage satchel (100% weight reduction) that isolates contained item count from the character backpack (reporting only 1 item for the satchel itself), automatically intercepts and stores gathered resources upon harvest, and safely holds recall runes. | Double-click to open |
| [`SanctuaryWard.cs`](SanctuaryWard.cs) | Blessed Talisman of Sanctuary that suppresses hostile creature aggro and targeting against the carrier and their pets while outdoors in the wild across all facets (including Felucca). Automatically suppresses inside dungeons and champion arenas, and allows retaliation if attacked. | Double-click to toggle, or `[GetSanctuary` |
| [`SayGump.cs`](SayGump.cs) | Ultra-compact (155x185), universal quick-speech "Say" gump accessible anywhere. Features tabbed sections for House management ("Lock Down", "Secure", "Release", "Unsecure", "Trash Barrel", "Ban", "Eject") and Boat navigation (Continuous sail, one-tile nudges, turns, emergency halt) with native speech keyword integration. | `[say`, `[tillerman`, `[house`, `[boat` |
| [`SlowSkillGrind.cs`](SlowSkillGrind.cs) | Progressive hours-based skill gain and cap breakthrough system past 100.0 (Grandmaster) up to 120.0 (Legendary) without requiring PowerScrolls. Implements tiered cooldown intervals (Tier 1 [100-105]: 6h; Tier 2 [105-110]: 12h; Tier 3 [110-115]: 18h; Tier 4 [115-120]: 24h) per 5.0 points (50 gains of 0.1), while allowing PowerScrolls to instantly raise caps and enable unthrottled gains. Includes full world save persistence and a player command to view cooldown status. | `[SlowGrind`, `[SlowGrindInfo` |
| [`StarterKitDistribution.cs`](StarterKitDistribution.cs) | Provisions every new character with a Blessed Full Spellbook (all 64 spells), Blessed Runebook (20 charges), 16 blank recall runes placed in the satchel, indestructible auto-tools, Talisman of Sanctuary, and personal resource satchel, plus an account-level one-time cottage voucher, small boat deed, Ankh of Sacrifice deed, and House Moongate deed. | Character creation, login fallback, or `[ClaimStarterKit` |
| [`WildernessReagents.cs`](WildernessReagents.cs) | Automated procedural wilderness ground reagent spawning system across Trammel and Felucca. Spawns standard magery reagents (1–3 yield) tailored to terrain (Swamps, Beaches, Mountains, Forests) concentrated in active mainland and island zones with surface Z calculation, decay suppression while in the wild, configurable world cap (1,500), periodic replenishment, and world save persistence. | Periodic timer (15m default), or GM admin command `[WildReagents` (`respawn`, `clear`, `reload`, `find`, `goto`, `near`) |
